# Симулятор экзамена и Асинхронный загрузчик изображений

![Python Version](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-completed-success)

Репозиторий содержит реализацию двух проектов на *Python*: **Симулятор сдачи экзамена** и **Асинхронный загрузчик изображений**.

Цель — применение на практике ООП, функционального и процедурного подходов, а также изучение асинхронного и многопроцессного программирования в Python.

## Реализованные проекты

### 1. Симулятор экзамена (`exam_simulator`)

Консольное приложение, моделирующее процесс сдачи экзамена студентами у нескольких преподавателей в режиме реального времени.

**Ключевые особенности реализации:**

- **Многопроцессность:** Каждый экзаменатор работает в отдельном процессе (`multiprocessing`), имитируя независимую работу.
- **Clean Architecture:** Проект разделен на слои:
  - `domain` — бизнес-сущности (Студент, Экзаменатор, Вопрос).
  - `application` — логика проведения экзамена и анализа результатов.
  - `infrastructure` — вывод статистики в консоль (`printer`) и сохранение состояния (`storage`).
- **Вероятностные модели:** Реализован алгоритм выбора ответов на основе закона золотого сечения, учет пола студента, настроения экзаменатора и случайных временных задержек.
- **Консольный интерфейс:** Динамическое обновление таблиц (студенты, экзаменаторы, время, очередь) без вывода новой информации поверх старой.
- **Правила оценки ответов:**
  - Экзаменатор задаёт студенту три вопроса из банка.
  - Студент выбирает одно слово из вопроса случайно, но с вероятностью, зависящей от пола (мальчики чаще выбирают слова ближе к началу, девочки — к концу) и закона золотого сечения.
  - Экзаменатор также случайно выбирает «верные» слова, причём может добавить ещё одно слово с вероятностью 1/3, затем ещё и ещё, пока не остановится или не выберет все слова.
  - Итоговое решение зависит от настроения экзаменатора:
    - плохое (1/8) — студент считается провалившим;
    - хорошее (1/4) — студент считается сдавшим;
    - нейтральное (5/8) — оценка объективная: сдал, если верных ответов больше, чем неверных, иначе провалил.
- **Аналитика:** В конце программы формируется подробная сводка:
  - **Лучшие студенты** — те, кто сдал экзамен быстрее всех.
  - **Лучшие экзаменаторы** — те, у кого процент заваленных студентов ниже, чем у остальных.
  - **Отчисленные студенты** — провалившие экзамен, закончившие раньше других проваливших.
  - **Лучшие вопросы** — вопросы, на которые верно ответило больше всего студентов.
  - **Итог экзамена** — считается удавшимся, если сдало больше 85% студентов.

### 2. Асинхронный загрузчик изображений (`async_downloader`)

CLI-утилита для параллельного скачивания изображений по ссылкам с отказоустойчивым вводом данных.

**Ключевые особенности реализации:**

- **Асинхронность:** Использование `asyncio` для одновременной загрузки нескольких изображений без блокировки основного потока.
- **Ограничение соединений:** Использование `asyncio.Semaphore` для ограничения максимального количества одновременных загрузок (по умолчанию — 10).
- **HTTP-клиент:** Библиотека `aiohttp` для асинхронных запросов и стримингового чтения данных.
- **Работа с файлами:** `aiofiles` для неблокирующей записи файлов на диск чанками (по 1024 байта).
- **Валидация URL:** Проверка протокола (`http/https`), наличия домена, имени файла и расширения перед началом загрузки.
- **Проверка контента:** Валидация заголовка `content-type` (скачиваются только файлы с типом `image/*`).
- **Неблокирующий ввод:** Использование `asyncio.to_thread(input, ...)` для ввода ссылок пользователем без блокировки Event Loop.
- **Отчетность:** Формирование ASCII-таблицы через `prettytable` с результатами успешных и неуспешных загрузок.

## Стек технологий

### Симулятор экзамена

- **Язык:** Python 3.10+
- **Многопроцессность:** `multiprocessing` (`Process`, `Queue`, `Event`, `Manager`), синхронизация через `Lock`, общие данные через `DictProxy` и `ValueProxy`.
- **Время и задержки:** `time.perf_counter`, `time.sleep`.
- **Вероятностные модели:** `random.choices`, `random.randint`, `random.uniform`, `random.sample`.
- **Работа с файлами:** `pathlib.Path`.
- **ООП:** `enum` для статусов и настроений, `uuid4` для уникальных идентификаторов.
- **Архитектура:** разделение на слои `domain` / `application` / `infrastructure`.
- **Консольный интерфейс:** `prettytable`, `os.system`.

### Асинхронный загрузчик

- **Язык:** Python 3.10+
- **Асинхронность:** `asyncio` (Event Loop, Tasks, Semaphore, `asyncio.to_thread`).
- **HTTP и файлы:** `aiohttp`, `aiofiles`.
- **Валидация и утилиты:** `urllib.parse`, `pathlib.Path`, `os`.
- **Консольный интерфейс:** `prettytable`.

## Как запустить

Для работы программы требуется Python 3.10 или выше.

### 1. Подготовка окружения

Склонируйте репозиторий, перейдите в корневую директорию.
Создайте и активируйте виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установка зависимостей

Установите необходимые библиотеки из файла `requirements.txt`

```bash
pip install -r requirements.txt
```

### 3. Запуск проектов

#### Симулятор экзамена

```bash
python3 src/exam_simulator/main.py
```

#### Асинхронный загрузчик изображений

```bash
python3 src/async_downloader/main.py
```
